# Preview Skill

Opens the index.html file in the default browser for previewing the application.

## Usage

Run `/preview` to open the HTML file in your default browser.

## Instructions

When the user invokes this skill, open the index.html file in the default browser using the Windows `start` command:

```bash
start "" "C:\Users\mark.korby\OneDrive - Capstone Technology Corporation\!dataparc_ai\dataparc_chat_assistant_mockup\index.html"
```

After running the command, confirm to the user that the preview has been opened in their browser.
